# 知识库文件追加格式规范

## 人设.md 追加格式

```markdown
## 《剑起白玉京》- 拆书积累

### 主角：陈少白
- **身份**：落难世子，从囚徒起步
- **性格标签**：隐忍、果决、重情义
- **核心欲望**：找到灭门真相，复仇雪恨
- **痛点**：身世成谜，被人追杀
- **成长弧线**：囚徒→修炼者→复仇者→守护者
- **人设吸引力**：起点极低+背景神秘，读者有探索欲

### 重要配角
- **苏云岚**：冰山美人，功能=提供线索+情感线，与主角互补
- **赵铁柱**：憨厚好友，功能=衬托主角+提供笑点

### 反派设计
- **秦无道**：压迫力=实力碾压+智商在线，动机=争夺资源不择手段
- **功能**：制造紧迫感，迫使主角快速成长

### 人设搭配逻辑
- 主角（隐忍+果决）+ 女主（高冷+温柔）= 情感张力
- 主角（严肃）+ 好友（憨厚）= 节奏调剂

---
```

### 转折设计
- **第一次重大转折**（第20章）：发现师父是仇人，从信任→怀疑

## 爽点.md 追加格式

```markdown
## 《剑起白玉京》- 拆书积累

### 爽点类型清单
| 类型 | 章节 | 结构 | 效果 |
|------|------|------|------|
| 扮猪吃虎 | 第5章 | 被轻视→展现实力→打脸 | 强烈 |
| 升级碾压 | 第15章 | 苦修→突破→碾压旧敌 | 中等 |
| 宝物获得 | 第22章 | 发现→争夺→险胜 | 强烈 |

### 爽点密度
- 平均每3章一个小爽点，每10章一个大爽点
- 爽点占比：铺垫60%：释放40%

### 有效爽点模式
- **模式1**：被看不起→暗中准备→公开打脸（最有效）
- **模式2**：遇到危险→绝境→突破反杀（次有效）

---
```

## 节奏.md 追加格式

```markdown
## 《剑起白玉京》- 拆书积累

### 开篇节奏
- **第1章**：悬念（追杀）+ 身份抛出 + 被迫离开 → 钩子：去哪？
- **第2章**：途中遇险 + 获得金手指线索 → 钩子：金手指是什么？
- **第3章**：到达新环境 + 冲突升级 → 钩子：怎么活下去？

### 章节节奏模板
- **黄金公式**：前半章铺垫/冲突，后半章释放/爽点，末段钩子
- **每章字数**：2000-2500字，节奏紧凑

### 钩子系统
| 类型 | 示例 | 频率 |
|------|------|------|
| 悬念钩 | "他万万没想到，身后那双眼..." | 每章末 |
| 对话钩 | "你确定要这么做？" | 每3章 |
| 事件钩 | 突然出现的追杀令 | 每5章 |

---
```

## 金手指.md 追加格式

```markdown
## 《剑起白玉京》- 拆书积累

### 金手指设定
- **名称**：天机神瞳
- **类型**：辅助型（鉴定+推演）
- **来源**：祖传血脉觉醒
- **规则**：消耗灵力使用，越级使用会反噬

### 金手指边界
- **限制**：每天只能使用3次，超过会昏迷
- **代价**：每次使用消耗大量灵力，需要恢复
- **冷却**：间隔1小时以上

### 升级路线
- **阶段1**（1-30章）：只能鉴定物品
- **阶段2**（31-80章）：可以推演功法
- **阶段3**（81-150章）：可以推演敌人攻击

### 与剧情耦合
- 金手指不是万能解，每次使用都有代价，反而增加剧情张力
- 金手指驱动主线：主角需要金手指揭开身世之谜

---
```
