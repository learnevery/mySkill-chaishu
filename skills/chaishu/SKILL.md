# 网文拆书（拆文）技能

## 一句话定义

不是写读后感、不是复述剧情、更不是抄书；是逆向解剖市场验证过的爆款网文，剥离表层故事，扒出它能留住读者、产生付费的工业化叙事逻辑，转化成自己可以复用的创作工具库。

普通读书是接收故事；网文拆书是研究这套故事为什么能火。这是网文作者的行业基本功，新人破自嗨、老作者破瓶颈都靠它。

## 核心红线（必须遵守）

- **拆写作机制、情绪模型、节奏范式，不窃取情节、人设、桥段。**
- **借鉴骨架，拒绝复制血肉。**
- 拆书 ≠ 洗稿：洗稿是换名字换背景照搬剧情，属于抄袭，与正规拆书完全两码事。
- 拆书 ≠ 读后感、≠ 复述剧情：只记录"发生了什么"没有意义，要记录"作者为什么这么安排"。

## 选书原则

- **拆近不拆远**：优先近期爆款（飙升榜、新书榜），老神作是时代产物，现在照搬会水土不服。
- **拆同赛道**：只拆与用户写作目标同赛道的书，不要跨赛道乱拆。
- **用榜单数据选书**：通过 rank_data_query 查询番茄/起点的飙升榜、新书榜、畅销榜、在读榜，找同赛道近期验证过的爆款。

## 工作流程（拆-提炼-仿写-内化 闭环）

### Step 1: 明确目标与选书
先确认：
- 用户写什么赛道/类型（都市高武？玄幻？悬疑灵异？）
- 用户想解决什么问题（新书没点击？节奏崩？写不出爽点？开篇劝退？）
- 选择拆书模式（粗拆 or 深度细拆）

用 rank_data_query 查同赛道近期榜单（数据来源说明）：
- 番茄畅销榜/在读榜：source=ranking
- 番茄新书榜：source=newbook
- 番茄首秀：source=debut
- 番茄细分榜单（人气/热搜/黑马/新书等）：source=allrank（不确定榜单先调 action=rank_names）
- 起点（月票榜/新书榜）：source=qidian
- 不确定分类名先调 action=categories；查整体概览用 action=stats
- 查榜单 top 用 action=top（limit 可调）

### Step 2: 获取正文
- 用户提供了正文/章节文件 → 用 file_read 读取
- 用户只给了书名 → 优先用 web_search 或让用户提供正文
- 没有正文无法拆书，需向用户说明并请其提供

### Step 3: 按模式拆解
选择粗拆或深度细拆（见"两种拆书模式"），按五大维度拆解，读取 references/五大维度拆解手册.md 对照检查清单逐项进行。

### Step 4: 提炼可复用范式
把故事外壳剥离，提取：
- 可复用的开篇公式、钩子类型清单
- 情绪节奏模板（铺垫→释放的曲线、比例）
- 人设-金手指-冲突的搭配逻辑
- 赛道高频模块清单及使用时机

### Step 5: 仿写训练（只拆不写=白拆）
换世界观、换人物，套用提炼出的叙事逻辑，写一段仿写片段（300-800字）。参照 references/仿写训练指南.md。

### Step 6: 内化清单
输出"下次写自己书时要主动运用的 X 条"行动清单。

## 两种拆书模式

### 模式A：粗拆（扫榜用，1-2小时）
- 只看前 10-20 章
- 输出：开篇任务、核心卖点、主要人设、开篇节奏
- 适合快速摸清赛道风向，批量对比多本书
- 粗拆一本书 → 至少写 1 个仿写片段

### 模式B：深度细拆（攻克瓶颈用）
- 选一本，挑一个完整故事单元（一个大副本/一个完整情节单元）
- 逐章标记：每一章的冲突、爽点、憋屈点、钩子、信息输出
- 反推：作者写这一章的目的是什么，为什么这里要安排这个事件
- 输出：完整拆书报告 + 可复用范式清单 + 仿写训练
- 深拆一本书 → 至少写 2-3 个仿写片段

## 五大拆解维度（概览，详见 references/五大维度拆解手册.md）

1. **卖点与开篇（黄金三章）**：书名简介钩子、前300-1000字、章末钩子类型、信息抛出顺序
2. **人设体系**：主角欲望痛点、金手指边界频率、配角反派衬托、冲突来源
3. **节奏与情绪曲线**（最核心）：爽点铺垫与释放、高潮密度、甜虐坑伏笔、支线穿插
4. **大纲与故事结构**：主线分卷、危机递进、赛道高频通用模块
5. **赛道读者偏好**（市场层面）：同赛道读者吃哪种梗、雷点是什么

## 输出格式

拆书报告保存到项目目录 `拆书/` 下，**统一输出双格式文件**：

| 文件 | 命名 | 用途 |
|---|---|---|
| Markdown | `拆书报告-{书名}-{模式}.md` | 数据层：可检索、可入库、可编辑，使用 references/拆书报告模板.md |
| HTML | `拆书报告-{书名}-{模式}.html` | 展示层：浏览器阅读/分享，使用 assets/report-template.html 模板生成 |

**HTML 生成规则（必读 references/html输出规范.md）**：
- 读取 `assets/report-template.html`，保留其全部 CSS、导航结构与折叠脚本，只替换正文内容
- HTML 内容与 MD 一一对应，不新增不删减；封面字段、表格、callout、仿写片段、页脚红线声明均按规范填充
- 两份文件一起交付（present_files 同时展示 md + html）

报告结构：
1. 书籍信息与选书理由
2. 核心卖点与开篇拆解
3. 人设体系拆解
4. 节奏与情绪曲线拆解
5. 大纲与故事结构拆解
6. 赛道读者偏好分析
7. 可复用范式清单
8. 仿写训练片段
9. 内化行动清单

## 重要规则

- 不写读后感、不复述剧情：只记录"发生了什么"没有意义，要记录"作者为什么这么安排"
- 逐章标记用表格，一目了然
- 拆书报告必须包含"可复用范式"和"仿写训练"，否则等于白拆
- 严格区分：扫榜（泛读榜单感知风向）、拆书（深度解剖提炼方法论）、洗稿（抄袭，禁止）
- 借鉴骨架，拒绝复制血肉；任何产出都不得照搬剧情、桥段、人物设定
