# HTML 输出规范（拆书报告）

拆书报告统一输出**双格式**：

| 文件 | 用途 | 命名 |
|---|---|---|
| Markdown | 数据层（可检索、可入库、可编辑） | `拆书报告-{书名}-{模式}.md` |
| HTML | 展示层（浏览器阅读、分享、演示） | `拆书报告-{书名}-{模式}.html` |

两份文件内容必须**一一对应**：HTML 是 MD 的精排版，不新增、不删减实质内容。

## 使用模板生成

1. 读取 `assets/report-template.html`（完整的页面骨架，含全部 CSS、可折叠导航、折叠脚本）。
2. **不要改动** `<style>` 内的任何样式、导航结构、`<script>` 脚本。
3. 按下面规则替换正文，把占位符（`【…】`）和 HTML 注释替换为报告内容。
4. 保存到项目 `拆书/` 目录，文件名与 MD 同名不同后缀。

## 页面结构映射（MD → HTML）

| Markdown 元素 | HTML 写法 |
|---|---|
| 封面（书名/作者/分类/字数/章节/在读/评分/拆解范围） | `.cover` 块内逐项替换 `【…】` |
| 目录 | `<nav>` 保持 9 个链接不动；粗拆删掉的 section 要同步删除对应 `<a>` |
| 章节标题（一、二、三…） | `<section id="sX"><h2><span class="idx">X</span>标题</h2>` |
| 小节标题（x.y） | `<h3>x.y 标题</h3>` |
| 普通段落 | `<p>…</p>` |
| 无序列表 | `<ul><li>…</li></ul>` |
| 有序列表 | `<ol><li>…</li></ol>` |
| 强调句（一句话结论、情绪曲线） | `<span class="em">…</span>` |
| 加粗关键字段 | `<strong>字段</strong>` |
| 表格（逐章标记、雷点清单等） | `<div class="tbl-wrap"><table><thead><tr><th>…</th></tr></thead><tbody>…</tbody></table></div>` |
| 结论/说明框（"作者为什么这么安排"等） | `<div class="callout"><b>标题</b>：内容</div>` |
| 可复用范式中的公式链 | `<span class="formula"><span class="k">关键节点</span> → …</span>` |
| 仿写片段正文 | `<div class="snippet"><p>…</p></div>`（每段一个 `<p>`） |
| 仿写自评 | `<div class="self"><b>自评</b>：…</div>` |
| 内化行动清单 | `<ul class="check"><li><span class="num">1.</span>…</li></ul>` |

## 组件使用要点

- **`<span class="em">`**：只用于一句话级别的核心结论/情绪曲线/关键判断，别滥用。
- **`.callout`**：放"作者为什么这么安排""为什么 X"这类**反推结论**，这是拆书报告的精华位置，务必保留。
- **`.pill` 颜色语义**（钩子类型/状态标签，统一用这套）：
  - `pill red` = 危机钩子
  - `pill gold` = 利益/期待/信息差钩子
  - `pill blue` = 悬念/世界观信息钩子
  - `pill green` = 爽点/新目标钩子、规避状态
- **表格**：单元格内容为空/无内容时写 `—`；逐章标记表必须含"作者目的"列。
- **仿写片段**：每个片段 = `h3` 标题（含换皮方向）+ 保留骨架说明（`<strong>`）+ `.snippet` 正文 + `.self` 自评，缺一不可。
- **折叠导航**：不要改 `id="nav"` / `id="navToggle"` 和脚本，折叠功能依赖它们。

## 内容红线（与拆书红线一致）

- HTML 只做排版，不新增分析、不扩写正文。
- 仿写片段只保留叙事骨架，世界观/人名/能力全部换皮（同 MD 内容）。
- 页脚"拆书红线自查"声明**必须保留**，书名与拆解范围替换为实际值。
- 引用原文句子（如简介、关键台词）保留引号与原文，不做改写。

## 粗拆适配

- 粗拆报告若只含部分章节，删除不需要的 `<section>`，并同步删除 `<nav>` 中对应的 `<a>`，其余结构不变。
- 标题保持"一、二、三…"连续编号（删除后重新编号），锚点 `#sX` 与导航一一对应。
