# 拆书报告模板

## 粗拆报告模板（模式A：扫榜用）

```markdown
# 粗拆报告：{书名}

## 书籍信息
- 书名 / 作者 / 分类 / 字数 / 连载状态
- 数据（在读数/评分/榜单排名，来自 rank_data_query）
- 选书理由：为什么拆这本（同赛道近期爆款？飙升榜？新书榜？）

## 开篇任务
- 前 10 章完成了什么（立人设、亮金手指、抛主线、埋第一个目标）？
- 主角初始状态 / 核心欲望 / 金手指一句话

## 核心卖点
- 书名/简介的钩子逻辑
- 这本书靠什么留住读者（3 条以内）

## 主要人设
- 主角 / 金手指 / 主要配角 / 反派 各一句话

## 开篇节奏
- 第一个冲突在第几章？第一个爽点在第几章？
- 章末钩子类型统计
- 前 10 章的情绪曲线（憋屈→爽 的节奏）

## 可复用范式（3-5 条）
- ...

## 一句话结论
- 这本书适合学什么、不适合学什么
```

## 深度细拆报告模板（模式B：攻克瓶颈用）

```markdown
# 深度细拆报告：{书名}

## 一、书籍信息与选书理由
- 基本信息 + 榜单数据
- 拆解目标：解决什么瓶颈（节奏？开篇？人设？）
- 拆解范围：第 X 章 - 第 X 章（完整故事单元：{副本/情节单元名}）

## 二、核心卖点与开篇拆解
（对照五大维度手册·维度一）

## 三、人设体系拆解
（对照五大维度手册·维度二）

## 四、节奏与情绪曲线拆解（核心）
- 逐章标记表
- 铺垫/释放比例统计
- 情绪曲线描述（文字）
- 高潮分布

## 五、大纲与故事结构拆解
（对照五大维度手册·维度四）

## 六、赛道读者偏好分析
（对照五大维度手册·维度五）

## 七、可复用范式清单
- 开篇公式
- 钩子类型库
- 情绪节奏模板
- 人设-金手指-冲突搭配逻辑
- 赛道高频模块清单

## 八、仿写训练
- 仿写说明（换掉什么世界观/人物，保留什么叙事逻辑）
- 仿写片段（300-800 字）

## 九、内化行动清单
- 下次写自己书时要主动运用的 X 条
```

## 报告书写注意事项
- 禁止写读后感、禁止复述剧情
- 每个观察都要回答"为什么作者这么安排"
- 每个维度都要落到"可复用范式"，否则等于白拆
